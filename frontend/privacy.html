UBETRA privacy

This install is self-hosted. The person who runs the server controls the account database, backups, and who can sign in.

The Android app can keep a private log on the phone when no server is configured, or when the configured server cannot be reached. That log is stored on the device. When a server is reachable, the phone sends pending chastity and orgasm entries to that server with the signed-in account.

The watch does not store account tokens and does not call the server. It exchanges encrypted messages with the paired phone.

Optional Health Connect reads stay on the phone until you sync them. Push notifications use the server you configured. This app does not ship a website-blocking VPN.
