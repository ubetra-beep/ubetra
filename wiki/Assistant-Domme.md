# Assistant Domme

Keyholder-only co-pilot. Partner **Chat is never sent to the model**. Subs keep human Chat.

Open it from:

- **Tracking**, **Playtime**, **chastity**, **orgasm log**, and **tasks** — labeled **Chat with Assistant**
- Full page `/#/dynamic/{id}/assistant/chat`
- A labeled **Assistant** bubble (bottom-right) on other dynamic pages when AI is on

On screens the assistant can coach (tracking, chastity, tasks, punishment, Playtime, and the rest of the catalog) the bubble turns **teal**. Tap it for a back-and-forth about **that screen** — not the full subject list. Use **All subjects** or the Playtime/Tracking buttons for the full index.

The bubble floats. Drag it to move (position is remembered on this device). Tap **×** on the bubble to hide it. Show it again from:

- the teal/purple edge tab on any dynamic screen
- hub **☰ → Show Assistant bubble**
- Chat **⋯ → Show Assistant bubble**
- Settings → AI → **Show Assistant bubble**

The bubble stays visible if AI is on even when no API key is set. Tap still opens the sheet; chatting needs a key. **Apply** cards work without a key (for example a demo task).

Chat tools (full sheet / full page): **Clear all messages** moves Assistant threads to trash for 7 days; **Recover** restores them. After 7 days they are permanently deleted.

Live data sent to the model follows the [context maps](Context-maps): a compact catalog of every area, plus live packs for the current screen only. Follow-up turns do not re-dump the whole dynamic.

## Subjects index

The sheet and full page list conversation subjects. Triggers badge the bubble and can pre-select a subject:

| Subject | When it fires |
|---------|----------------|
| What can assistant do? | Always — example prompts and demo Apply cards |
| Open conversation | Always |
| This page | Always — uses the current screen’s capabilities |
| Goal coach | Always — gift goals + standing targets, easier vs tighter |
| Feature audit | Always — unused enabled modules; optional disable |
| Orgasm review | Always — both partners, this window vs last |
| Chastity review | Always — hours, % locked, breaks |
| Suggest a tease | Always — one idea, then “another direction?” |
| Suggest a punishment | Always — only if a confession is pending |
| Suggest service | Always — domestic / sexual / sensual / degrading |
| Review a confession | Pending punishment self-report the keyholder has not opened here |
| Task drought | Few or no open assigned tasks |
| Orgasm balance | Sub orgasms rising vs keyholder / standing target |
| Lockup trend | Lockup hours or % locked falling vs last window / target |
| Inbox | Overdue, late, make-up, pending punishments |
| Journal review | New partner-visible journals |
| Goal progress | Gift goals look ready to grant |
| Scene ideas | Manual — opens Playtime scene builder |

Opening a triggered subject asks whether the drift is **intentional** or whether to adjust targets, tasks, or lockup policy. Coaching subjects invent a specific idea, then offer an easier vs more challenging fork for this **day / week / month**.

## Permissions (agent)

Mutations are never silent. Each Apply card checks a grant:

| Level | Meaning |
|-------|---------|
| Ask (default) | First tap: Allow once / this session (12h) / always / don’t allow |
| Session | Allowed until logout or 12 hours |
| Always | Apply without asking |
| Don’t allow | Blocked |

Capabilities: assign tasks, standing targets, gift goals, optional feature toggles, punishment tasks, open screens (open defaults to always). Still **never** auto lock/unlock, complete tasks, or send partner Chat.

Grants are Dom-controlled. Set them on the Assistant page under **Permissions**. Logout clears session grants.

## Confirm-to-apply cards

Replies (and the **What can assistant do?** intro) show **Apply** cards: assign a task, adjust a standing or gift goal, toggle an optional feature, assign a punishment task, or jump to a screen. **What can assistant do?** seeds example cards so you can see Apply without waiting on the model.

---

## Change log

Every successful Apply appends **Changes from chat** and a Chat system event (when activity logs are on). Later Assistant turns can see recent changes.

---

## Standing balance targets

Gift/unlock goals stay on Tasks → Goals. **Goals & balance** (orgasm log, chastity, and Tasks → Goals) are weighted standing targets:

- Metric (orgasms to keyholder, sub orgasms, ratio, lockup hours, percent locked, open tasks)
- Weight 1–5 (3+ nags the bubble; 1–2 stay in the index)
- Target, direction (at least / at most / hold), lookback days
- Live **current** vs previous window and trend

## Without AI

Turn off AI in Settings, or skip the shared key. Then:

- Interview is a **table of prompts** instead of a chat
- Assist buttons are hidden
- Playtime still offers Tasks, Instructor, and games
- Act types can be added by hand
- Assistant bubble and Chat with Assistant hide when AI is off; with AI on and no key, the entry stays and Apply cards still work
